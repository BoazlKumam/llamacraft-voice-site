Frequently Asked Questions

Do I need to run a server?

If you play on an existing server, only the server host needs to run the voice server binary or Paper plugin. Players just install the companion app on their phone or PC and it connects automatically when you join the world.

Is Bedrock Voice Chat free?

Yes. The software is 100% free, open-source, and self-hosted with zero subscription paywalls or premium tiers.

How do console players (Xbox, PS, Switch) use voice chat?

Because Xbox, PlayStation, and Nintendo Switch cannot run background third-party background software, console players simply run the free companion app on their phone or tablet while playing on console. The app tracks your in-game coordinates and handles microphone audio seamlessly.
