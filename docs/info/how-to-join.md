# How to Join LlamaCraft

You can play on LlamaCraft using almost any device that runs Minecraft!

---

## Server Connection Addresses (Playit.gg)

| Platform | Server Address (IP) | Port | Supported Versions |
| :--- | :--- | :--- | :--- |
| **Java Edition (PC / Mac / Linux)** | `approaching-icc.tun.ply.gg` | `9256` | `1.20` - `1.21` |
| **Bedrock (Phone, iPad, Windows)** | `approaching-icc.tun.ply.gg` | `9256` | Latest Bedrock |
| **Consoles (Xbox, PlayStation, Switch)** | Via ScholarCraft, Bedrock DNS, or App | `9256` | Latest Bedrock |
| **Home Wi-Fi (Local LAN Only)** | `192.168.0.176` | Java: `25565`<br>Bedrock: `19132` | Any |

---

## 1. Java Edition (PC & Mac)

1. Open Minecraft Java Edition (`1.20` or `1.21`).
2. Click **Multiplayer** then **Add Server**.
3. Put `LlamaCraft` as the Server Name.
4. Type `approaching-icc.tun.ply.gg:9256` as the Server Address.
5. Click **Done** and double-click to join!

---

## 2. Bedrock (Phone, iPad, Tablet, Windows 10/11)

### Method A: Direct Playit IP
1. Open Minecraft on your phone, iPad, or computer.
2. Click **Play** and tap the **Servers** tab at the top.
3. Scroll down and tap **Add Server**.
4. Fill in:
   - **Server Name**: `LlamaCraft`
   - **Server Address**: `approaching-icc.tun.ply.gg`
   - **Port**: `9256`
5. Click **Play** to join!

### Method B: Join Through ScholarCraft
You can also connect to LlamaCraft directly through the **ScholarCraft** server network from Bedrock:
1. In your Bedrock **Servers** list, add **ScholarCraft**.
2. Connect to ScholarCraft, and use the server selector to jump straight into LlamaCraft!

---

## 3. Consoles (Xbox, PlayStation, Nintendo Switch)

Consoles don't have an "Add Server" button by default, but you can join easily using any of these methods:

### Method A: MC Server Connector App (Mobile LAN Bridge)
1. Download the free app called **MC Server Connector** (or **BedrockTogether**) on your phone.
2. Connect your phone to the same home Wi-Fi as your console.
3. In the phone app, type IP `approaching-icc.tun.ply.gg` and Port `9256`, then tap **Start**.
4. On your console, open Minecraft, go to **Friends**, and look under **LAN Games**. Click `LlamaCraft` to join!

### Method B: BedrockConnect DNS
1. Go to console **Network Settings** > **DNS Settings** > set to **Manual**.
2. Set Primary DNS to `104.238.130.180` and Secondary DNS to `1.1.1.1`.
3. Join any featured server (like The Hive). A custom server menu will appear.
4. Select **Connect to a Server**, type `approaching-icc.tun.ply.gg` and Port `9256`.
